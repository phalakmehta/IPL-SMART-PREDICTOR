A lightweight web application that predicts the win probability of the chasing team in an Indian Premier League (IPL) match in real-time. 

Built using a **Logistic Regression** model to provide fast, interpretable probability estimates based on match context (target, current score, balls left, wickets, etc.).

## Tech Stack
* **Machine Learning:** Logistic Regression (scikit-learn)
* **Frontend:** Streamlit
* **Data Processing:** Pandas & NumPy
